# BSDM-Proxy v0.9.14

**Release date:** 2026-08-31  
**Type:** minor/feature release  
**Previous tag:** v0.9.13

## Highlights

- **Threat Intelligence Data-Plane Enforcement & Triple-Gate Guardrails** — full IOC pipeline integration with `TI_ENFORCEMENT_MODE=enforce`, lock-free `arc_swap::ArcSwap` snapshot matching, Corporate Allowlist precedence, and zero-downtime hot-reloads.
- **Enterprise SIEM & Automated SOAR Integrations** — threat detection exports in CEF (ArcSight/QRadar/Splunk), ECS JSON (Elastic), and Syslog RFC 5424 formats with UDP/TCP/file transports; RESTful SOAR containment API (`/api/v1/soar/*`) and ML campaign clustering & typosquatting detection (`/api/v1/ml/*`).
- **Dynamic RPZ Live Telemetry & Automated Rollback** — live zone status inspection (`/api/v1/rpz/status`), emergency atomic rollback (`/api/v1/rpz/rollback`), and automated live reload webhooks for `dns-sinkhole`.
- **AmneziaWG Protocol Integration & BSDM Connect Client** — native WireGuard/AWG tunnel provisioning with Curve25519 cryptography, pre-shared keys, device revocation synchronization, and cross-platform `bsdm-connect` daemon and CLI.
- **Domain Split-Routing & Dynamic PAC Generator** — on-device traffic split policies (`Direct`, `Proxy`, `Tunnel`, `Block`) and secure JavaScript PAC script generation with strict escaping and CSRF defense.
- **Argon2id Password Storage & Automated Migration** — upgraded basic authentication credentials store to Argon2id with automatic in-place migration on login and strict 0600 file permission validation.
- **CIS Benchmark Hardening & Automated Compliance Auditor** — comprehensive CIS benchmark alignment for Docker, Helm PSS Restricted, NGINX, and Systemd with automated compliance testing (`scripts/audit-cis-benchmarks.sh`) and SARIF security scanning workflows.
- **SOC Operations & Triage UI** — interactive IOC investigation modal with 1-click whitelist/containment, brand phishing inspector, and live device configuration drift monitoring in the Admin Console.

## Upgrade

1. Pull or build the `v0.9.14` images or packages.
2. Preserve `/etc/bsdm-proxy`, `/certs`, and persistent data volumes.
3. If using basic authentication, passwords in `basic-auth-users.json` are automatically upgraded to Argon2id upon the first successful authentication.
4. For threat intelligence live integration, review [ADR 0008](../adr/0008-threat-intel-shadow-mode.md) before switching from `TI_ENFORCEMENT_MODE=shadow` to `enforce`.
5. Verify `/health`, `/ready`, `/metrics`, and `/admin/` on port `9090`.
6. Validate archive downloads with the adjacent `.sha256` file.

No intentional breaking control-plane API changes.
