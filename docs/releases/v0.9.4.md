# Release v0.9.4

**Тип:** patch release (v0.9.4)  
**Дата:** 2026-08-04  
**База:** `main` (after v0.9.3)

> Optional **agent control mTLS transport**: dedicated HTTPS port requiring
> client certificates. Full notes: [CHANGELOG.md](../../CHANGELOG.md).

## Highlights (с v0.9.3)

### Agent control mTLS

- `CONTROL_MTLS_ENABLED=true` → HTTPS listener (default `0.0.0.0:9443`)
- **Client certificate required** (trust = proxy/agent CA)
- Plain `METRICS_PORT` stays HTTP for Prometheus and Admin Console
- Optional `CONTROL_MTLS_REQUIRE_ENROLLED` — fingerprint must match enrolled device
- Paths: `/api/v1/agent/*`, `/api/v1/devices*`, `/health`

Guide: [pilot-agent.md](../getting-started/pilot-agent.md) ·
[control-plane-security.md](../ops-and-dev/control-plane-security.md).

## Upgrade from 0.9.3

1. No change required if mTLS port is unused (default off).
2. To enable: set `CONTROL_MTLS_ENABLED=true`, ensure CA + enrolled client certs
   (`agent-spike --enroll --mtls`), optionally `CONTROL_MTLS_REQUIRE_ENROLLED=true`.
3. Firewall: publish `:9443` only to agent networks; keep `:9090` management-only.

## Still reserved

- CRL / OCSP, policy push, multi-OS installers
- mTLS on primary metrics port (intentionally not done)
