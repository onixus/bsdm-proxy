## Upgrade from 0.9.0

1. Keep `CONTROL_API_TOKEN` / `SEARCH_API_TOKEN` (production still requires them).
2. Ensure `DLP_ENABLED` is unset or `false` unless you intentionally enable experimental DLP.
3. For auth pilots: set `BASIC_AUTH_USERS_FILE` (do not rely on open Basic without a users file).
4. DNS: bring up `dns-sinkhole` and run `./scripts/run-dns-pilot-smoke.sh`.

No intentional breaking API changes vs 0.9.0; default DLP-off is the main
behavior change if you previously relied on built-in signatures without setting
`DLP_ENABLED`.
