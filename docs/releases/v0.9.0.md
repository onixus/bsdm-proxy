# Release v0.9.0

**Тип:** stable release (v0.9.0)  
**Дата:** 2026-08-04  
**База:** `main`

> Pilot-hardening release for Hybrid Policy: production control-plane auth,
> SNI never-MITM invariant, single Admin Console operator UI, CA rotation,
> decision-source observability, pinning exceptions, and reproducible pilot
> load-test profiles. Full notes: [CHANGELOG.md](../../CHANGELOG.md).

## Highlights (с v0.8.0)

### Security & policy

- Production **requires** `CONTROL_API_TOKEN` (fail closed); lab override
  `CONTROL_API_ALLOW_INSECURE` only ([#271](https://github.com/onixus/bsdm-proxy/issues/271))
- `POLICY_MODE=sni` **never** terminates TLS — unit + e2e
  ([#272](https://github.com/onixus/bsdm-proxy/issues/272))
- `POLICY_MODE=full-mitm` blocked in production without `ALLOW_FULL_MITM`
- Admin Console mutations fail closed without API token
- Two-phase **CA rotation** tooling + offline drill
- wasmtime security patch (RUSTSEC-2026-0222 / 0223)

### Pilot & operations

- Hybrid **pilot compose** + acceptance checklist
  ([#270](https://github.com/onixus/bsdm-proxy/issues/270))
- **100-user load-test** profile + CI hybrid job + results archive
  ([#269](https://github.com/onixus/bsdm-proxy/issues/269))
- `METRICS_BIND`, optional metrics scrape Bearer
- Default proxy port docs aligned to **3128**

### Observability & data plane

- `decision_source` metrics / logs / Search filters (`dns|sni|mitm|pinning-bypass`)
- Managed **pinning exceptions** registry + audit trail
- Search API pagination & sorting; ClickHouse schema compatibility

### Operator UI

- Admin Console is the **only** supported operator UI (`/admin/`)
- Legacy `/trust` redirects; standalone Trust-UI is experimental profile only

## Upgrade notes

1. Set strong `CONTROL_API_TOKEN` (and `SEARCH_API_TOKEN` if Search API is enabled)
   before upgrading production — the proxy **refuses to start** without them
   unless `CONTROL_API_ALLOW_INSECURE=true` (lab only).
2. Review [control-plane-security.md](../ops-and-dev/control-plane-security.md)
   for bind/network recommendations (`METRICS_BIND`).
3. Prefer pilot path: `docker compose -f docker-compose.yml -f docker-compose.pilot.yml`.
4. If you relied on standalone Trust-UI, enable profile `experimental-trust-ui`
   or migrate operators to `/admin/`.
