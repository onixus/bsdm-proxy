# BSDM-Proxy v0.9.13

**Release date:** 2026-08-21  
**Type:** patch release  
**Previous tag:** v0.9.12

## Highlights

- **Threat intelligence feed collector (`threat-intel`)** — optional worker ingesting OpenPhish, PhishStats, Phishing.Database and URLhaus on a schedule with retry/backoff, intra-batch deduplication, Prometheus metrics (`:8093/metrics`), and JSONL snapshots + `report.json` (`TASK-TI-001`).
- **Proxy hot-path performance & lock optimization** — eliminated per-request allocations and lock contention across the proxy request engine: in-place ACL snapshot matching, sharded `PolicyDecisionCache` (`RwLock`), direct slice-based host & category parsing, atomic sampling, and static Prometheus metric label pools.
- **ACL policies & domain fallbacks** — added built-in categories and fallbacks for social networks and cloud file hosting with preconfigured deny policies.
- **Interactive installer redesign** — revamped `./install.sh` (`scripts/interactive-install.sh`) with root requirement deferral, portable helper functions, and automated CI installer validation.
- **Security & dependency fixes** — upgraded `h2` to `0.4.16` for RUSTSEC-2026-0258; fixed double event sampling on cache MISS/DLP violation paths; hardened Admin Console token bootstrap and config persistence.
- **CI & tooling** — added local Jenkinsfile pipeline support, Semgrep SAST, and Gitleaks security quality gates.

## Upgrade

1. Pull or build the `v0.9.13` images or packages.
2. Preserve `/etc/bsdm-proxy`, `/certs`, and persistent data volumes.
3. For Threat Intelligence feed collection, enable the Compose profile (`--profile threat-intel`), Helm toggle (`threatIntel.enabled`), or systemd unit (`bsdm-threat-intel.service`).
4. Verify `/health`, `/ready`, `/metrics`, and `/admin/` on port `9090`.
5. Validate archive downloads with the adjacent `.sha256` file.

No intentional breaking control-plane API changes.
