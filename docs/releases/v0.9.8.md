## Upgrade from 0.9.7

No breaking API changes. Optional enablement:

```bash
# Multi-node agent store
export AGENT_DEVICES_REDIS_URL=redis://redis:6379/0

# OS proxy (on the endpoint)
bsdm-agent --set-system-proxy

# WebSocket policy (agent-spike)
export AGENT_POLICY_WS=1
```
