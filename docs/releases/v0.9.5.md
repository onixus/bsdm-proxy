# Release v0.9.5

**Тип:** patch release (v0.9.5)  
**Дата:** 2026-08-04  
**База:** `main` (after v0.9.4)

> Agent **policy push**: long-poll, SSE, and operator notify so devices refresh
> policy without waiting for the next heartbeat pull. Full notes:
> [CHANGELOG.md](../../CHANGELOG.md).

## Highlights (с v0.9.4)

| Endpoint | Purpose |
|---|---|
| `GET /api/v1/agent/policy/watch?since=&timeout_secs=` | Long-poll until version changes |
| `GET /api/v1/agent/policy/stream` | SSE `event: policy` |
| `POST /api/v1/agent/policy/push` | Operator rebuild + notify |

Also: auto-push after pinning exception reload; `agent-spike` enables the watch
loop by default (`AGENT_POLICY_PUSH=0` to disable).

Guide: [pilot-agent.md](../getting-started/pilot-agent.md).

## Upgrade from 0.9.4

No breaking changes. Agents on older spikes keep working via periodic pull;
new spikes receive pushes when the control plane publishes.

```bash
curl -X POST -H "Authorization: Bearer $CONTROL_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"reason":"ops","actor":"ops"}' \
  http://127.0.0.1:9090/api/v1/agent/policy/push
```
