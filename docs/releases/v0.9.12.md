# BSDM-Proxy v0.9.12

**Release date:** 2026-08-12  
**Type:** patch release  
**Previous tag:** v0.9.11

## Highlights

- Hardened RKN ACL enforcement while preserving URL/domain/IP scope.
- Added configurable fallback registry source and persistent last-known-good snapshot.
- Readiness now fails closed when RKN is enabled but no validated registry is available.
- Added registry-source provenance to RKN decisions and audit logs.
- CI, security audit, and load-test gates for the RKN hardening change are green.

## Upgrade

1. Pull or build the `v0.9.12` images or packages.
2. Preserve `/etc/bsdm-proxy`, `/certs`, and persistent data volumes.
3. Persist `RKN_SNAPSHOT_PATH` (default `/var/lib/bsdm-proxy/rkn-registry.json`) across container or pod recreation.
4. Verify `/health` and `/ready`; with RKN enabled, readiness requires a validated registry or LKG snapshot.
5. Validate archive downloads with the adjacent `.sha256` file.

No intentional breaking control-plane API changes.
