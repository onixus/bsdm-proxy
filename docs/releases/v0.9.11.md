# BSDM-Proxy v0.9.11

**Release date:** 2026-08-06  
**Type:** patch release  
**Previous release:** v0.9.10

## Highlights

- Refactored Admin Console foundations and modular Settings UI.
- Fixture-backed Chromium smoke test across every console route.
- Same-origin Search integration and file-backed RPZ management.
- Safer live configuration Apply semantics.
- Package checksums, GHCR SBOM, provenance, and stronger release validation.

## Upgrade

1. Pull or build the `v0.9.11` images or packages.
2. Preserve `/etc/bsdm-proxy`, `/certs`, and persistent data volumes.
3. Do not restore generated RPZ state from source control.
4. Verify `/health`, `/ready`, and `/admin/` on port `9090`.
5. Validate archive downloads with the adjacent `.sha256` file.

No intentional breaking control-plane API changes.
