# Release v0.9.7

**Тип:** patch release (v0.9.7)  
**Дата:** 2026-08-04  
**База:** `main` (after v0.9.6)

> Agent **RFC 6960 DER OCSP** and **gRPC policy** product path. Full notes:
> [CHANGELOG.md](../../CHANGELOG.md).

## Highlights (с v0.9.6)

| Surface | Purpose |
|---|---|
| `POST /api/v1/agent/ocsp` | RFC 6960 DER OCSP (CA-signed ECDSA/RSA) |
| `GET /api/v1/agent/ocsp?b64=` | Base64 GET form of OCSP request |
| gRPC `GetAgentPolicy` | Pull current policy document |
| gRPC `PushAgentPolicy` | Operator rebuild + notify |
| gRPC `WatchAgentPolicy` | Server stream of policy publishes |

JSON lab OCSP (`/ocsp/status`) and HTTP long-poll/SSE policy remain available.

Guide: [pilot-agent.md](../getting-started/pilot-agent.md) ·
[agent-contract.md](../architecture/agent-contract.md) ·
[control-plane-security.md](../ops-and-dev/control-plane-security.md).

## Upgrade from 0.9.6

No breaking changes.

```bash
# DER OCSP (public — no Bearer)
curl -sS -X POST -H 'Content-Type: application/ocsp-request' \
  --data-binary @ocsp-req.der \
  http://127.0.0.1:9090/api/v1/agent/ocsp -o ocsp-resp.der

# gRPC (build --features grpc)
export CONTROL_GRPC_ENABLED=true
export CONTROL_GRPC_BIND=127.0.0.1:50051
```

## Still reserved (#273)

- Multi-OS installers / system proxy
- Multi-node shared device registry
- OCSP stapling on data-plane TLS
- WebSocket policy push (shipped on main after 0.9.7)
