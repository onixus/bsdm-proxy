# Субагенты BSDM-Proxy

Специализированные субагенты Claude Code для этого репозитория.
Вызываются автоматически по описанию или явно: «используй агента `appsec` для …».

| Агент | Роль | Когда звать |
|---|---|---|
| `cynical-security-architect` | Цинничный архитектор ИБ, ревьювер | Новый сервис/крейт, новый сетевой интерфейс, изменение модели доверия, MITM/TLS и PKI, схема мультитенантности. Ревью **дизайна** до кода. |
| `appsec` | AppSec-инженер | Изменения в разборе входных данных, HTTP-парсинге, auth, ACL, кэше, внешних интеграциях. Поиск **эксплуатируемых** уязвимостей в коде. |
| `devsecops` | DevSecOps-инженер | `Dockerfile`, `docker-compose.yml`, `charts/`, `deploy/`, `packaging/`, `Jenkinsfile*`, `.github/workflows/`, `scripts/`, конфиги Prometheus/Grafana/Alertmanager. |
| `senior-developer` | Сеньор Rust-разработчик | Реализация фич, багфиксы, рефакторинг в крейтах воркспейса; доведение до зелёных `fmt` / `clippy` / `test`. |

## Разделение зон

- **Архитектор** спорит о дизайне и границах доверия, код не правит.
- **AppSec** ищет конкретные баги безопасности в коде приложения, с вектором и фиксом.
- **DevSecOps** отвечает за сборку, поставку и рантайм — не за код приложения.
- **Senior developer** единственный, кто по умолчанию пишет код крейтов.

## Типовой конвейер

```
идея/дизайн → cynical-security-architect
       ↓
реализация  → senior-developer
       ↓
код-ревью   → appsec  (+ cynical-security-architect, если менялась архитектура)
       ↓
поставка    → devsecops
```

Правила проекта, которым следуют все агенты, — в корневом `AGENTS.md`
и `.agents/AGENTS.md`; карта модулей — в `.agents/context-map.md`.
